# Клиника Надёжа — образец сайта медцентра

Внутренний статический сайт-пример для отрасли «медицина / услуги».

## Как открыть локально

### Вариант 1 — просто открыть файл
1. Перейдите в папку `cases/medicine/`.
2. Откройте `index.html` в браузере (двойной клик или «Open with…»).

### Вариант 2 — локальный сервер (предпочтительно)
Из корня репозитория:

```bash
cd cases/medicine
python3 -m http.server 8080
```

Затем откройте в браузере: [http://localhost:8080](http://localhost:8080)

## Что внутри
- `index.html` — одностраничный сайт с якорями
- `css/styles.css` — стили и адаптив
- `js/main.js` — мобильное меню и сообщение «Заявка принята»
- `case.md` — описание кейса
- `screenshots/` — папка под скриншоты (список экранов — в `case.md`)

## Примечание
Форма записи демонстрационная: данные никуда не отправляются.
