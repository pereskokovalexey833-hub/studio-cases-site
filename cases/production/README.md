# ПромСнаб Регион — сайт-образец

Внутренний статический сайт-визитка для отрасли «производство / оптовые поставки».

## Как открыть локально

### Вариант 1 — просто файл
Откройте `index.html` в браузере (двойной клик или «Open with…»).

### Вариант 2 — локальный сервер
Из папки `cases/production/`:

```bash
# Python 3
python3 -m http.server 8080
```

Затем откройте в браузере: http://localhost:8080

или:

```bash
npx --yes serve -l 8080
```

## Состав
- `index.html` — страница сайта
- `css/styles.css` — стили
- `js/main.js` — меню и форма заявки
- `case.md` — описание кейса
- `screenshots/` — список экранов для скриншотов (см. `case.md`)
