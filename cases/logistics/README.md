# ТрансЛиния 72 — образец сайта (логистика)

Внутренний проект студии: статический сайт логистической компании для B2B-перевозок.

## Как открыть локально

### Вариант 1 — просто открыть файл
Откройте `index.html` в браузере (двойной клик или «Open with…»).

### Вариант 2 — локальный сервер
Из этой папки:

```bash
# Python 3
python3 -m http.server 8080
```

или

```bash
# Node.js (если установлен)
npx --yes serve -l 8080
```

Затем откройте в браузере: http://localhost:8080

## Структура

- `index.html` — страница сайта
- `css/styles.css` — стили
- `js/main.js` — меню и форма заявки
- `case.md` — описание кейса
