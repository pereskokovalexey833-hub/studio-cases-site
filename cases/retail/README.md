# Пекарня Утро — образец сайта (розница / общепит)

Внутренний одностраничный сайт-образец студии. Стек: HTML + CSS + минимальный JS.

## Как открыть локально

### Вариант 1 — просто файл
Откройте `index.html` в браузере (двойной клик или «Open with»).

### Вариант 2 — локальный сервер
Из папки `cases/retail/`:

```bash
# Python 3
python3 -m http.server 8080
```

или

```bash
# Node.js (если установлен)
npx --yes serve -l 8080
```

Затем откройте в браузере: http://localhost:8080

## Что проверить
- Hero с фото хлеба и крупным брендом
- Полоса фактов под героем
- Якорная навигация: Меню, Зал, Адреса, Бронь, Контакты
- Фильтр категорий в меню (10 позиций)
- Галерея «Утро в зале»
- Форма брони: после отправки появляется «Заявка принята» (без реальной отправки)
- Мобильное меню на узкой ширине экрана

## Файлы
- `index.html` — разметка
- `styles.css` — стили
- `script.js` — меню, фильтр, форма
- `images/` — фото героя и галереи (локально, чтобы страница не зависела от CDN)
- `case.md` — описание кейса
- `screenshots/` — кадры для портфолио
